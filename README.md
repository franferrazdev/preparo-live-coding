# 🚀 Preparatório para Entrevistas de Live Coding (Front-End)

Este repositório foi criado para centralizar meus estudos, treinar lógica de programação, manipulação de DOM Vanilla e consumo de APIs assíncronas focando em processos seletivos de Front-End.

## 🎯 Objetivos

- Dominar os fundamentos do JavaScript Vanilla (ES6+).
- Resolver problemas de estruturas de dados e algoritmos (padrão LeetCode/HackerRank).
- Praticar a comunicação técnica e cenários com mudanças de regras (variações).

## 📂 Desafios Implementados

- [ ] **Contador Dinâmico:** Manipulação de eventos, gerenciamento de estado simples e validação de limites (com variação de passos dinâmicos).
- [ ] **Filtro de Lista em Tempo Real:** Filtragem de arrays e manipulação de nós na árvore DOM de forma performática.

### 🌐 Integração com APIs

- [ ] **Renderização de Cards de Usuários:** Uso de `async/await`, manipulação de Promises, tratamento de erros HTTP (`response.ok`) e estados de Loading.

### 🧮 Algoritmos & Estruturas de Dados (LeetCode / HackerRank)

- [ ] **Two (O(n)):** Otimização de busca linear utilizando Mapas/Objetos de frequência para evitar loops aninhados (O(n²)).
- [ ] **Anagrama Válido:** Comparação e contagem de caracteres ignorando espaços e letras maiúsculas.
